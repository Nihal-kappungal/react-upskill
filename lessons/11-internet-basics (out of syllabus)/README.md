## What I Understood

A domain name is a human-readable name that points to an IP address.

When a user enters a domain:

Browser
→ DNS
→ IP Address
→ Web Server
→ Response
→ Browser

I also learned how a website can be hosted on a cloud server and accessed through the internet.

## Why I'm Learning This

As a frontend developer, I don't want to only know how to write React components.

I want to understand what happens after I type a URL into the browser and how my application reaches the user.
